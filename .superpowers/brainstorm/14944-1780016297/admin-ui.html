前端后台包含 4 个核心页面

1

任务路由配置

Handler ↔ 飞书表映射、触达平台选择、目标群配置、字段映射

2

群映射管理

钉钉群/企微群的 ID 管理，群名称与群 ID 的对应关系

3

用户映射管理

飞书 ↔ 钉钉/企微用户 ID 映射，同步状态，手动补充

4

任务监控 & 日志

任务执行状态看板、消息发送记录、错误日志、催办记录
