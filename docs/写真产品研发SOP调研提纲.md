# 写真产品研发 SOP 跨部门调研提纲

> **用途：** AI部门与写真产品研发团队逐阶段对齐实际工作流程，收集AI融合所需的细节信息。
> **使用方式：** 每个阶段单独开会讨论，先让对方描述实际工作流程，再用下方问题逐项确认和深挖。

---

## 调研前准备

向研发团队说明以下几点：
- 本次调研目的是了解实际工作流程的每一个具体步骤，不做评判
- 需要了解"实际怎么做的"，不是"理想中应该怎么做的"
- 关注每个步骤中哪些环节最耗时、最依赖经验、最容易出问题
- 调研结果将用于设计内部AI工具，帮助团队提升效率

## 阶段1：风格定义与趋势洞察

### 1.1 趋势信息来源

**需要获取的信息：**
- 当前从哪些渠道获取风格趋势信息？（社交媒体、展会、竞品、其他）
- 信息收集的频率和节奏是怎样的？（每日/每周/每月/每季度？）
- 每次收集的信息量大概有多少？如何存放和整理？
- 有没有固定的信息源清单？还是随机搜索？

**讨论点：**
- 信息收集过程中哪些环节最耗时？
- 信息来源是否有盲区？有没有觉得"别人总能比我先看到新趋势"的感觉？
- 历史趋势信息是否有归档？能否回溯"去年这个时候流行什么"？

**提问清单：**
1. 你们平时从哪里了解最新的风格趋势？能列举几个具体的信息源吗？
2. 每天花多少时间在趋势信息的收集上？
3. 收集到的信息是怎么整理的？存在哪里？文件夹、文档还是其他形式？
4. 大概多久做一次趋势信息的集中梳理？
5. 有没有觉得某些趋势信息特别难获取或者获取不及时？
6. 过去的趋势资料会保留吗？需要的时候能找到吗？

### 1.2 趋势分析与判断

**需要获取的信息：**
- 从"看到趋势"到"判断这个趋势值不值得追"的决策过程是怎样的？
- 趋势判断主要依赖谁的经验/直觉？有没有可量化的标准？
- 判断一个趋势"适合我们品牌"的标准是什么？
- 趋势的生命周期判断依据是什么？

**讨论点：**
- 趋势判断的成功率如何？有没有追过后来凉了的趋势？
- 有没有错过后来爆了的趋势？当时为什么没追？
- 判断过程中有没有发生过团队意见分歧？怎么解决的？

**提问清单：**
1. 当你们看到一个新趋势时，怎么判断它值不值得跟进？具体的判断标准是什么？
2. 这个判断主要依赖谁来做？是负责人拍板还是团队讨论？
3. 有没有出现过追了某个趋势但市场反响不好的情况？事后复盘过原因吗？
4. 有没有出现过犹豫没追、后来发现爆了的情况？
5. 如果现在要你把"判断趋势是否适合我们品牌"的标准写下来，你觉得能写清楚吗？

### 1.3 灵感整理与内部讨论

**需要获取的信息：**
- 灵感分享/头脑风暴的频率和形式？（会议、群聊、共享文档？）
- moodboard（灵感板）的制作流程和工具？
- 参与讨论的人员角色有哪些？（摄影师、造型师、设计师、市场、管理层？）
- 从灵感到确定方向一般要经历几轮讨论？

**讨论点：**
- 灵感讨论中最大的障碍是什么？（表达不清、审美差异、决策慢？）
- moodboard 的制作是否耗时？复用性如何？
- 历史灵感讨论的结果是否有记录？

**提问清单：**
1. 你们的灵感讨论通常是什么形式？频率是怎样的？
2. moodboard 是怎么制作的？用什么工具？一般花多长时间？
3. 参与讨论的人有哪些角色？每个人的关注点分别是什么？
4. 从提出灵感到最终确定方向，一般要讨论几次？
5. 过去做过的灵感板和讨论记录会保留吗？需要参考历史方案时方便找吗？
6. 讨论中最常出现的问题是什么？

### 1.4 风格方向初步定义

**需要获取的信息：**
- 风格方向提案文档包含哪些内容？有固定模板吗？
- 风格命名和关键词的确定方式？
- 目标人群画像的依据？（历史客户数据、市场调研、经验判断？）
- 情绪价值定位是如何确定的？
- 提案的审批流程是怎样的？

**讨论点：**
- 风格定义的描述是否足够结构化？能否用标签/关键词体系来标准化？
- 目标人群画像的准确性如何验证？
- 提案被驳回的主要原因通常是什么？

**提问清单：**
1. 你们的风格方向提案文档大概长什么样？能给我看一个示例吗？
2. 风格的名称和关键词是怎么定出来的？
3. 目标人群画像你们是怎么画的？依据什么数据或信息？
4. 你们会定义"这套写真的情绪价值"吗？比如"青春感"、"高级感"？怎么定义的？
5. 提案提交后走什么审批流程？一般多久能批下来？
6. 提案被打回过吗？主要是什么原因？

## 阶段2：主题策划与产品定义

### 2.1 主题创意细化

**需要获取的信息：**
- 从"风格方向"到"具体主题"的转化过程是怎样的？
- 主题命名的规范和逻辑？
- 一个风格方向通常衍生出几个主题？
- 主题与季节/节日/热点的关联方式？

**讨论点：**
- 主题创意过程中最依赖谁的创意能力？
- 历史主题中哪些特别成功？哪些表现一般？有没有做过归因？

**提问清单：**
1. 确定了风格方向之后，怎么把它变成具体的拍摄主题？
2. 主题的命名有什么讲究或规律吗？
3. 一般一个风格方向会衍生出几个主题方案？
4. 季节、节日、热点事件在主题策划中占多大比重？
5. 回顾过去一年，哪个主题最成功？哪个最不理想？你们觉得原因是什么？

### 2.2 拍摄方案策划

**需要获取的信息：**
- 拍摄方案的完整内容包含哪些？（场景、服装、妆面、道具、姿态、情绪……）
- 方案策划由谁负责？需要哪些角色配合？
- 方案策划的参考素材从哪里来？（自己拍过的历史、竞品、网络素材？）
- 方案策划的平均周期是多长？

**讨论点：**
- 方案策划中哪些元素最容易卡住或反复修改？
- 参考素材的整理和复用效率如何？
- 方案策划与成本预算的联动机制？

**提问清单：**
1. 一份完整的拍摄方案包含哪些内容？有模板可以看看吗？
2. 方案策划由谁主导？摄影师、造型师还是专门的策划角色？
3. 你们做方案时参考素材主要从哪里找？找素材大概花多长时间？
4. 方案策划从启动到定稿一般要多久？
5. 方案中哪个部分最容易反复修改或产生分歧？
6. 服装、道具、场景的成本预算是在这个阶段就确定的吗？

### 2.3 产品定价与包装

**需要获取的信息：**
- 定价策略和依据？（成本加成、市场对标、价值定价？）
- 产品包装/套餐设计的方式？
- 不同价格带的产品定位差异？
- 定价与目标人群的匹配验证方式？

**讨论点：**
- 定价决策的数据支撑程度？
- 定价与实际销售结果的相关性分析？
- 产品包装差异化要素的确定逻辑？

**提问清单：**
1. 新产品的定价是怎么定出来的？主要考虑哪些因素？
2. 套餐设计（包含几张、什么场景、什么服务）有什么固定的设计逻辑吗？
3. 不同价格带的产品在定位上有什么明确差异？
4. 定价完成后有没有做过"这个价格卖不卖得动"的预判？预判准确吗？
5. 历史产品中，定价与销量/利润的关系你们有分析过吗？

### 2.4 产品定义文档输出

**需要获取的信息：**
- 产品定义文档的完整内容和格式？
- 文档的审批和确认流程？
- 文档传递给下一环节（视觉设计/拍摄）的方式？
- 文档版本管理和变更机制？

**讨论点：**
- 文档是否足够结构化，能否被标签化/数字化？
- 文档传递中是否存在信息损失或理解偏差？

**提问清单：**
1. 最终的产品定义文档包含哪些内容？能看一个样本吗？
2. 这份文档谁审批？审批周期一般多久？
3. 文档传给执行团队后，对方理解会有偏差吗？有没有出现过"做出来的跟想的不一样"的情况？
4. 文档内容在中途有修改过吗？修改频率高吗？怎么管理的？
5. 如果要把这份文档的所有关键信息用标签/关键词表达，你觉得可行吗？

## 阶段3：视觉方案设计

### 3.1 妆面造型设计

**需要获取的信息：**
- 妆面设计的流程和参与角色？
- 造型设计参考素材的来源？
- 造型与风格的对应关系是否有标准？（比如"复古风=红唇+波浪卷"这样的规则）
- 造型设计的试妆流程？

**讨论点：**
- 造型设计中经验依赖度有多高？
- 造型与风格的匹配度如何量化评估？
- 试妆的迭代次数和耗时？

**提问清单：**
1. 妆面造型设计是谁负责？化妆师独立完成还是跟策划/摄影师一起讨论？
2. 造型设计的参考从哪里来？每次都是新找还是有积累的造型库？
3. 同一种风格对应的造型有没有相对固定的"公式"或"模板"？
4. 试妆一般要试几次？每次试妆的调整方向是怎么定的？
5. 试妆结果怎么评估好坏？有没有客观标准？

### 3.2 服装搭配设计

**需要获取的信息：**
- 服装选品的渠道和流程？（自有服装库、采购、定制？）
- 服装与风格/主题的匹配标准？
- 服装搭配的方案数量（一套主题配几套服装）？
- 服装采购/准备的周期？

**讨论点：**
- 服装库的管理效率？（分类、检索、状态追踪）
- 服装复用率如何？
- 服装成本占总成本的比例？

**提问清单：**
1. 服装是自有的还是需要外采/定制？比例大概是？
2. 现有服装库有多大？有没有做过分类管理？
3. 给一个新主题配服装时，怎么判断"这件衣服适合这个主题"？
4. 服装的复用率高吗？有没有很多只拍了一次就闲置的？
5. 服装从确定方案到准备就绪一般需要多久？

### 3.3 场景设计

**需要获取的信息：**
- 场景类型？（实景棚、实景外景、虚拟背景？）
- 场景搭建/选择的流程？
- 场景与风格/主题的匹配标准？
- 场景道具的管理方式？

**讨论点：**
- 场景搭建的成本和周期？
- 场景的可复用性？同一场景改造为不同主题的频率？
- 场景设计中最依赖创意还是最依赖执行？

**提问清单：**
1. 你们的拍摄场景主要是棚拍还是外景？比例大概？
2. 棚景是固定的还是每次新搭？搭建周期和成本大概怎样？
3. 场景设计由谁负责？设计师还是摄影师？
4. 场景和主题的匹配关系有没有积累过经验？（比如什么主题适合什么材质/颜色的背景）
5. 场景道具怎么管理？有没有道具库？

### 3.4 配色与视觉基调确定

**需要获取的信息：**
- 配色方案的制定流程？
- 配色与风格/情绪的对应规则？
- 配色方案的表达方式？（色卡、参考图、调色预设？）
- 配色在不同环节（妆面、服装、场景、后期）的一致性如何保证？

**讨论点：**
- 配色是否有可量化的标准？（如具体色值范围）
- 配色跨环节传递中是否容易出现偏差？

**提问清单：**
1. 配色方案是怎么确定的？有专门的色彩设计环节吗？
2. 配色方案用什么形式表达和传递？（色卡？参考图？）
3. "这个配色代表什么情绪/风格"这种对应关系，团队内部有共识吗？
4. 配色从设计到最终成片，中间经过妆面、服装、场景、后期多个环节，一致性怎么保证？
5. 有没有出现过最终成片颜色跟预期不一致的情况？原因是什么？

### 3.5 整体视觉方案评审

**需要获取的信息：**
- 视觉方案的评审流程和参与人？
- 评审标准和打分方式？
- 方案被驳回的主要原因？
- 评审到定稿的平均迭代次数？

**讨论点：**
- 评审的主观性如何控制？
- 评审中"好看/不好看"这类主观判断是否可转化为更具体的评价维度？

**提问清单：**
1. 视觉方案评审是哪些人参与？每个人看重的点分别是什么？
2. 评审有没有打分机制或者评价维度？（还是凭感觉说"好/不好"？）
3. 方案被打回最常见的理由是什么？
4. 从初版到定稿一般要改几轮？
5. 如果要让评审更客观，你觉得可以加哪些评价维度？

## 阶段4：样片拍摄执行

### 4.1 拍摄前准备

**需要获取的信息：**
- 拍摄前的准备清单包含哪些内容？
- 准备工作的责任分工？
- 拍摄前沟通会的流程和内容？
- 模特选择标准和流程？

**讨论点：**
- 准备过程中最常见的遗漏或问题？
- 模特与风格的匹配度如何判断？

**提问清单：**
1. 拍摄前一天/前几天会做哪些准备？有checklist吗？
2. 准备工作由谁统筹？谁负责检查完整性？
3. 模特是怎么选的？选择标准是什么？
4. 拍摄前会开沟通会吗？会上讨论什么？一般开多久？
5. 准备过程中最容易遗漏或出问题的是什么？

### 4.2 拍摄现场执行

**需要获取的信息：**
- 拍摄现场的人员配置和分工？
- 拍摄的典型流程？（先拍什么、后拍什么、每个场景拍多久？）
- 摄影师对被拍者的引导方式？（姿态、表情、情绪调动）
- 拍摄中的即兴调整频率和方式？
- 单次拍摄的产出量？（多少个场景、多少张原始片）

**讨论点：**
- 拍摄引导的经验依赖程度？
- 拍摄效率的关键瓶颈？（换装、换场景、模特状态？）
- 拍摄参数和设置是否有记录习惯？

**提问清单：**
1. 一次完整拍摄大概持续多长时间？中间怎么安排节奏？
2. 摄影师引导模特的方式是怎样的？有固定的引导套路还是现场发挥？
3. 拍摄过程中经常需要即兴调整方案吗？什么情况下会调整？
4. 一次拍摄大概产出多少张原始照片？
5. 拍摄时的相机参数、布光参数会有意识记录吗？
6. 拍摄现场最影响效率的环节是什么？

### 4.3 拍摄质量把控

**需要获取的信息：**
- 拍摄过程中的质量检查方式？（即时回看？边拍边选？）
- 质量标准有哪些？（构图、光线、表情、姿态、整体感觉？）
- 质量不达标时的处理方式？（重拍？后期补？放弃？）
- 拍摄现场与远程（不在场的策划/管理层）的沟通方式？

**讨论点：**
- 质量把控的主观性程度？
- 有没有可以量化的质量指标？
- 拍完发现质量不理想的频率和原因？

**提问清单：**
1. 拍摄过程中怎么判断"这张可以了"？标准是什么？
2. 是边拍边选还是拍完再统一选？
3. 如果拍出来的效果跟预期有差距，现场怎么处理？
4. 不在现场的策划人员怎么参与质量把控？
5. 回顾过去，拍摄质量不达标的常见原因是什么？

## 阶段5：后期制作与交付

### 5.1 粗选与精选

**需要获取的信息：**
- 选片流程和标准？
- 选片参与人和角色？
- 选片的耗时和节奏？（多久完成选片？）
- 选片与客户的关系？（客户参与选片还是内部选？）

**讨论点：**
- 选片的效率瓶颈？
- 选片标准的一致性？（不同人选出的片差异大吗？）
- 被淘汰的照片有没有被分析和归因过？

**提问清单：**
1. 选片分几轮？每轮的标准有什么不同？
2. 选片由谁负责？不同人选出来的差异大吗？
3. 选片一般花多长时间？是整个流程中比较耗时的环节吗？
4. 选片标准能写下来吗？还是主要凭经验？
5. 没被选中的照片有没有分析过"为什么没选"？（曝光问题、表情问题、构图问题？）

### 5.2 精修流程

**需要获取的信息：**
- 精修的标准和规范？
- 精修的平均耗时？（单张、整套）
- 精修的主要工作内容？（调色、磨皮、液化、背景处理？）
- 精修质量的一致性如何保证？（不同修图师的结果差异？）
- 精修的审核流程？

**讨论点：**
- 精修中最耗时的环节？
- 精修标准能否模板化/自动化？
- 精修风格一致性的管控难度？

**提问清单：**
1. 一张照片的精修大概要花多长时间？
2. 精修中最耗时的步骤是什么？
3. 不同修图师修出来的风格一致吗？怎么保证一致性？
4. 精修有固定的调色预设/动作包吗？还是每次手动调？
5. 精修完成后谁审核？审核标准是什么？
6. 精修环节的返工率高吗？主要是什么原因导致返工？

### 5.3 成品输出与归档

**需要获取的信息：**
- 成品交付的格式和标准？
- 成品的归档方式？（按产品/按时间/按风格？）
- 归档后的检索和复用效率？
- 样片与客片的关联管理方式？

**讨论点：**
- 成品归档的结构化程度？
- 历史成品的复用场景和效率？
- 归档体系是否支持按标签快速检索？

**提问清单：**
1. 成品照片最终以什么形式存储和管理？
2. 归档是按什么维度组织的？（产品名/日期/风格？）
3. 需要找历史照片时方便吗？大概要花多长时间？
4. 样片和实际客片有关联管理吗？（可以查到"这个产品实际拍出来的客片长什么样"？）
5. 有没有想过给每张成品打标签（风格、色调、情绪、场景等）？如果要做，现在有基础吗？

## 阶段6：上市与市场反馈

### 6.1 产品上线与推广

**需要获取的信息：**
- 新产品上线的推广渠道和方式？
- 推广素材的制作流程？（从成品到推广物料的转化）
- 推广预算分配逻辑？
- 上线初期（前1-2周）的关键指标关注点？

**讨论点：**
- 推广素材制作的效率和复用性？
- 推广渠道的选择是否有数据支撑？

**提问清单：**
1. 新产品上线一般在哪些渠道推广？推广节奏是怎样的？
2. 推广用的图片/视频素材是怎么做出来的？跟成品照片的关系是？
3. 推广素材的制作用什么工具？耗时多久？
4. 推广预算在不同渠道之间怎么分配？有依据吗？
5. 上线后最关注的指标是什么？怎么判断"这个产品开局不错/不行"？

### 6.2 销售数据监测

**需要获取的信息：**
- 销售数据的采集频率和维度？
- 销售数据与产品的关联方式？（能否追溯到"这个订单对应哪个产品"？）
- 销售数据看板的现有形态？
- 销售数据中的关键指标定义？

**讨论点：**
- 销售数据的实时性？
- 数据维度的丰富程度？（能否区分渠道、门店、时间、客户画像？）

**提问清单：**
1. 销售数据是怎么记录的？用的是什么系统？
2. 能否清楚地知道"某个产品在某个门店某段时间卖了多少单"？
3. 销售数据多久看一次？有实时看板吗？
4. 除了销量，你们还关注哪些销售相关指标？（客单价、复购率、转化率？）
5. 销售数据跟客户画像数据能关联起来吗？

### 6.3 客户反馈收集

**需要获取的信息：**
- 客户反馈的来源和收集方式？（评价、问卷、社交UGC、客服记录？）
- 客户反馈的整理和分析方式？
- 负面反馈的响应机制？
- 客户反馈与产品的关联方式？

**讨论点：**
- 客户反馈的覆盖率和代表性？
- 反馈从"收集"到"可用于决策"的转化效率？

**提问清单：**
1. 客户反馈主要从哪些渠道获取？
2. 反馈是有人专门整理分析，还是散落在各个地方？
3. 客户最常反馈的正面和负面内容分别是什么？
4. 负面反馈一般多快能传达到产品研发团队？
5. 有没有做过"客户反馈"和"产品调整"之间的闭环案例？

### 6.4 舆情监测（接入第三方平台）

**需要获取的信息：**
- 目前是否有使用舆情监测工具？
- 目前手动关注社交媒体的频率和方式？
- 希望从舆情数据中获取什么信息？
- 舆情数据与产品/品牌的关联需求？

**讨论点：**
- 舆情数据的业务化应用场景？
- 舆情预警的需求和标准？

**提问清单：**
1. 目前有没有在用任何舆情监测工具？（百度舆情、新浪舆情、清博等）
2. 目前团队是怎么了解"网上对我们品牌的评价"的？
3. 你们最希望从舆情数据中看到什么？（品牌声量、产品口碑、竞品对比、行业趋势？）
4. 舆情数据需要跟具体产品关联吗？（比如"某款产品在小红书上被讨论了什么"）
5. 有没有需要"舆情预警"的场景？（比如负面评价突然增多时需要及时知道）

## 阶段7：复盘与知识沉淀

### 7.1 产品表现复盘

**需要获取的信息：**
- 复盘的频率和触发条件？（定期/产品周期结束后/出现问题时？）
- 复盘参与人和流程？
- 复盘报告的内容和格式？
- 复盘中的关键分析维度？（销量、利润、客户满意度、市场口碑？）

**讨论点：**
- 复盘的深度和有效性？
- "成功原因"和"失败原因"的分析是否有数据支撑？
- 复盘结论是否转化为具体的改进措施？追踪了吗？

**提问清单：**
1. 复盘是怎么触发的？固定周期还是项目结束？
2. 复盘一般由谁主导？哪些人参加？
3. 复盘报告包含哪些内容？能看一个示例吗？
4. 复盘中"为什么成功/为什么失败"的归因主要靠什么？（数据？经验？讨论？）
5. 复盘产出的改进措施有追踪执行吗？实际执行率怎样？

### 7.2 经验沉淀与复用

**需要获取的信息：**
- 经验/知识沉淀的现有方式？（文档、案例库、培训？）
- 知识的检索和复用效率？
- 新员工的学习和上手路径？
- 历史产品案例的积累量？

**讨论点：**
- 知识沉淀是否系统化？
- "经验"是否可以转化为可传递的结构化知识？
- 知识复用的实际频率和效果？

**提问清单：**
1. 做过的产品案例有系统地整理和存档吗？
2. 如果新人想了解"我们过去做过什么类似的产品"，方便查到吗？
3. 优秀案例有没有作为参考模板复用过？复用效果如何？
4. 经验传承主要靠什么方式？（师父带、文档学习、培训分享？）
5. 有没有出现过"之前做过类似的东西但忘了/找不到"的情况？

### 7.3 标签体系与数据资产

**需要获取的信息：**
- 现有的产品分类/标签方式？
- 产品信息的结构化程度？
- 如果要给所有产品打标签，现有数据基础如何？
- 期望的标签维度有哪些？

**讨论点：**
- 标签体系的构建路径？
- 标签与B阶段研究的衔接需求？
- 数据资产的长期价值认知？

**提问清单：**
1. 你们现在给产品分类/打标签吗？怎么分的？
2. 如果要给每个产品打上"风格、色调、情绪、场景、人群、季节"等标签，现有信息能支持吗？
3. 这些标签你们觉得对日常工作有帮助吗？什么样的帮助？
4. 如果未来要做行业研究，你们觉得还需要积累什么数据？
5. 对于"把所有产品变成可检索、可对比、可分析的数据资产"这个方向，你们怎么看？

## 调研后整理要点

每次调研结束后，整理以下内容：
1. **实际SOP流程图** — 与团队确认后的实际工作步骤
2. **痛点清单** — 每个步骤中标注的耗时、依赖经验、容易出错的地方
3. **数据现状** — 目前已有的数据、缺失的数据、质量如何
4. **AI切入机会点** — 结合痛点和数据现状，标注可行的AI融合点
5. **优先级判断** — 结合影响面、实施难度、数据准备度，排列优先级
